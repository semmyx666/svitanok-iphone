# Світанок 0.7 — личный токен alerts.in.ua

1. В старой версии отключи активную серию и резерв.
2. Установи Svitanok-0.7-unsigned.ipa через iloader на Fedora с подписью своим Apple ID.
3. Открой Настройки. Сверху появился раздел «API-токен alerts.in.ua».
4. Вставь только ключ из письма и нажми «Сохранить токен».
5. Выбери район/громаду. Нажми «Проверить токен и подключение» (если сработала пауза, подожди 15 секунд).
6. Убедись, что написано «Токен принят». Активируй ночной режим со звуком для сна, если нужен перенос после отбоя с закрытым экраном.
7. Установи будильник заново: старый установленный план не меняет источник автоматически.
8. Проверь короткий звонок с блокировкой экрана; оставь отдельный резерв в «Часах» до проверки на своём iPhone.

Токен не встроен в IPA и отсутствует в исходниках. Он вводится на твоём iPhone, сохраняется в Keychain (без iCloud-синхронизации, после первой разблокировки, только это устройство) и передаётся исключительно в Authorization: Bearer для https://api.alerts.in.ua. Redirect запрещён. Есть кнопка удаления ключа.

Это личное прямое подключение. Для публичного распространения приложения с общим ключом правила alerts.in.ua требуют сервер-прокси; такой ключ нельзя встраивать в приложение. Ни сервер, ни платный хостинг для личного ключа здесь не добавляются.

Официальный API v1: A — воздушная тревога, P — частичная тревога, N — источник не сообщает тревогу. Для области используется массив из 27 позиций в документированном порядке; для выбранного района/громады — запрос с его UID. Некорректные, просроченные, пустые ответы, 401/403/429 и сетевые ошибки не считаются отбоем. Проверка не чаще раза в 15 секунд, при ошибках — увеличенная пауза.

Математический пример и серия 06:30 / 06:35 / 06:40 сохранены из 0.6. Системную Stop iOS убрать нельзя. Фоновое ожидание отбоя по-прежнему экспериментально, требует настоящего звука для сна; резерв может сработать при продолжающейся тревоге. Это не официальное приложение alerts.in.ua и не замена гражданской защите. Данные источника могут задерживаться.

# Світанок 0.2 — начните здесь

**В этом ZIP исходники и автоматическая сборка, НЕ уже собранный IPA.**

Основной бесплатный путь для вашего iPhone 13 / iOS 27.2:

1. Бесплатный аккаунт GitHub → публичный репозиторий → запустить включённый workflow.
2. GitHub macOS runner скомпилирует проект, выполнит Swift-тесты и, только при успехе, выдаст `Svitanok-unsigned.ipa`.
3. Скачать IPA на Windows и локально подписать/установить через Sideloadly с бесплатным Apple Account. Пароль не отправляется автору проекта и не хранится в GitHub.
4. Проверить обычный тест через 2 минуты на вашем реальном телефоне, оставив резерв в «Часах».

**Никакой платной подписки для этого пути не требуется.** GitHub Actions — бесплатная ОБЛАЧНАЯ сборка для публичного репозитория на стандартном runner, не локальная сборка в Windows/Fedora. Исходники станут публичными. Apple Account — аккаунт, не платная подписка. Без подходящей подписи установить произвольный IPA на обычный iPhone нельзя.

Подробно:
- `docs/WINDOWS_FEDORA_FREE_RU.md` — Windows, Fedora, бесплатная подпись, отсутствие подписок, команды и ошибки.
- `docs/FREE_DATA_PROXY_RU.md` — без VPS/домена: сервер на собственном ПК и временный бесплатный HTTPS-туннель.
- `docs/INSTALL_RU.md` — альтернативная установка с имеющимся Mac, собственный постоянный сервер.
- `docs/TEST_PLAN_RU.md` — реальные испытания телефона.
- `docs/DELIVERY_STATUS_RU.md` — что выполнено, что только подготовлено.

Обновление: сборка уже успешно выполнена в вашем GitHub-репозитории, 35 Swift-тестов прошли, unsigned IPA получен. Подтверждение в docs/BUILD_RECEIPT_RU.md. Если он красный, IPA не публикуется; скачать логи можно из Actions. Это реальный контроль, не заранее созданный пустой файл.

Системный обычный сигнал — через AlarmKit. Условный перенос по тревоге остаётся экспериментальным, только в открытом активном приложении. Работу «телефон заблокирован всю ночь → автоматически ждать отбой» версия 0.2 не обещает. Точные позиции дронов и ежедневные повторы не реализованы. Настроенный сервер нужен для статуса/переноса, но не для обычного сигнала.

# Світанок 0.5: ночной режим со звуком для сна

**Это не полностью беззвучный способ.** Всю ночь играет настоящий мягкий шум для сна. Он позволяет приложению оставаться в аудиофоне при заблокированном экране и проверять отбой. Нет своего сервера, платной подписки или API-ключа; нужен интернет для UA Siren.

## Как обновить

1. В старом приложении отключи текущий будильник и резерв.
2. Новый `Svitanok-0.5-unsigned.ipa` установи через тот же iloader на Fedora, которым уже установил прошлую версию. Подпись Apple ID остаётся отдельным шагом; неподписанный файл из Telegram сам не устанавливается.
3. При первом запуске разреши будильники.
4. Выбери «Вінницький район» (UID 36) либо нужную громаду, а не всю область. Источник — «Без ключа · UA Siren».
5. Сначала нажми «Тест отбоя · со звуком для сна». Он использует искусственные статусы и занимает около 2 минут. Прокрути главный экран вниз до надписи «Ночной звук играет», затем заблокируй экран.
6. После сигнала нажми «Я проснулся». Если вместо сигнала после отбоя прозвучал «проверка прервалась», сработал резерв — это не успешная проверка отбоя.
7. Для обычного утра включи в настройках «Ночной режим · отбой со звуком для сна» и оставь включённым «Звук для сна». Выбери время, нажми «Включить будильник», прокрути вниз до подтверждения воспроизведения и заблокируй экран. **Не закрывай приложение смахиванием.**

Настройки сохраняются для следующей установки. Звук для сна — не мелодия сигнала. Громкость регулируется iPhone; намеренно не делай ночь полностью беззвучной этим способом.

## Что произойдёт

- Нет тревоги: основной системный будильник сработает по времени.
- Есть тревога перед подъёмом: при свежих данных и работающем фоне сигнал переносится короткими проверенными резервами.
- После времени подъёма получен свежий отбой: ставится системный сигнал через 5 секунд. Проверки примерно каждые 15 секунд; задержки источника/сети добавляются. Не обещание конкретной секунды от официального объявления.
- Звук/интернет/процесс прервался: последний системный резерв остаётся; он может прозвучать **во время тревоги**, обычно в пределах минуты после последнего продления. Это защита от бесконечного переноса.
- Достигнут выбранный предел ожидания: резерв будит независимо от тревоги.

На телефоне могут прервать аудиофон звонок, другое аудиоприложение, закрытие приложения или iOS. Ночное испытание именно iPhone 13 не проведено в облаке. Оставляй независимый резерв в «Часах» и официальные оповещения о тревогах.

## Почему есть альтернативный переключатель

Без ночного звука приложение пробует BGContinuedProcessingTask. Симулятор отказал в этом методе с BGTaskSchedulerErrorDomain/1; подтверждения работоспособности этого варианта нет. При отказе основной сигнал не отменяется. Для текущего варианта используй настоящий звук для сна, не альтернативу.

## Техническая основа

Apple документирует воспроизведение с заблокированным экраном для AVAudioSession `.playback` с UIBackgroundModes `audio`:
https://developer.apple.com/documentation/avfaudio/avaudiosession/category-swift.struct/playback

Это разрешённое настоящее воспроизведение звука, не пустой WAV, не частные API и не имитация push-уведомлений. Короткий искусственный тест не подтверждает качество данных UA Siren и непрерывную работу всю ночь.

# Світанок — iPhone-прототип 0.2

**Это архив исходников, НЕ подписанный IPA и НЕ готовое проверенное приложение.**
Android пока не делался. Дата подготовки: 14 октября 2026.

## Самое важное перед установкой

1. Требуется **iOS 26+**. Для Windows/Fedora добавлена бесплатная macOS-сборка GitHub Actions; собственного Mac не нужно. Это облачный путь, публичный репозиторий и бесплатные аккаунты всё равно нужны. Начните с `START_HERE_RU.md`.
2. Проект теперь успешно собран на GitHub macOS runner: Xcode 26.6, 35 Swift-тестов без ошибок, ARM64 IPA упакован и проверен. Подробности в `docs/BUILD_RECEIPT_RU.md`. На физическом iPhone тестирование ещё не выполнено; unsigned IPA требует локальной подписи.
3. iOS не гарантирует постоянную работу приложения или проверку интернета точно в 06:30 при заблокированном экране. AlarmKit обеспечивает системный сигнал, но не произвольный запуск вашей сетевой логики по секундам.
4. Экспериментальный перенос работает **только пока приложение открыто и активно**. Не отключайте автоблокировку на всю ночь ради прототипа. Основной ночной сценарий «телефон заблокирован, гарантированно ждать отбой» НЕ реализован и не обещается.
5. Нет свежих данных / сервера / разрешения / подтверждённого резерва — нет автоматического переноса. Если разрешение на будильники не дано, сигнал вообще не установлен: читайте сообщение приложения.
6. Даже после переноса предельный резерв звонит через 30, 60 или 120 минут, в том числе при продолжающейся тревоге. Это компромисс против бесконечного ожидания, а не приказ выходить из укрытия.
7. **Оставьте отдельный резерв в системном приложении «Часы», особенно перед школой.** Прототип не должен быть единственным будильником.
8. Официальные оповещения и правила безопасности имеют приоритет. Отсутствие тревоги в API не доказывает безопасность. Не откладывайте действия по сигналам гражданской защиты.

## Реализовано в исходниках

Один ближайший будильник на выбранную дату и время. 27 областей/отдельных регионов из документированного порядка API; м. Київ отдельно от Київської області. Выбор системного звука или двух оригинальных мелодий, предпрослушивание своих мелодий. Системное разрешение AlarmKit. Тестовый обычный сигнал через две минуты. Включаемый экспериментальный перенос и жёсткий предел ожидания. Настройки сохраняются локально и применяются только к следующей установке.

До переноса серверные данные должны быть свежими, приложение — активным, основной и резервный сигналы — в состоянии scheduled. Проверка выполняется в окне 30–3 секунды до заданного времени. Active и Partial обрабатываются одинаково консервативно. При отбойном статусе после заданного времени новый системный сигнал ставится через 5 секунд; кнопка «Я проснулся» отменяет сигналы этой группы, включая резерв. Резерв не снимается просто от наличия нового ответа API.

Карта — веб-страница самого alerts.in.ua внутри приложения, а не скопированные данные/графика. Доступность и возможность отображения зависят от сайта; предусмотрена ссылка Safari. Нет собственной карты точных координат, направлений или подтверждённых маршрутов дронов. Сообщения о типах угроз на сайте не следует выдавать за точное слежение за объектами.

## Не реализовано / не проверено

- Гарантированный автоматический перенос при закрытом приложении, блокировке экрана или force-quit.
- Подписанный IPA, установка на ваше устройство, TestFlight-публикация. Unsigned IPA уже успешно собран.
- Много будильников, повторы по дням недели, бессрочное ежедневное расписание, snooze, пользовательский импорт аудио.
- Фоновая постоянная геолокация, точная карта дронов, обход системных ограничений iOS.
- Проверка реального API: токен не предоставлялся. Сервер не развёрнут.
- Проверка реального AlarmKit, громкости, перезагрузки, энергосбережения, поведения при отмене из системного интерфейса, подписи и срока её действия.

Не используются фиктивные фоновые аудиодорожки, постоянная GPS-слежка или обещания гарантированной доставки silent push. Простой APNs/BGAppRefresh-сервер не устраняет ограничения iOS.

## Источники и ограничения

- Apple AlarmKit и официальный пример: https://developer.apple.com/documentation/alarmkit/scheduling-an-alarm-with-alarmkit
- Фоновые задачи: https://developer.apple.com/documentation/backgroundtasks/choosing-background-strategies-for-your-app
- Документация alerts.in.ua, порядок регионов, токен и лимиты: https://devs.alerts.in.ua/
- Заявка на токен: https://alerts.in.ua/api-request
- Подключение iPhone к Xcode: https://developer.apple.com/documentation/xcode/pairing-your-devices-with-xcode

В 0.2 обновлены обработка остановки уже звучащих сигналов и сборочная инфраструктура. Статус основной ночной функции не изменился: надёжный перенос в заблокированном состоянии НЕ реализован.

API предназначен для сторонних приложений с персональным токеном; для публичного приложения источник требует прокси и запрещает встраивать токен в клиент. Его документация предупреждает о задержках и не рекомендует использование в критической инфраструктуре. Компактный код N означает, что источник не сообщает тревогу, а не физическую безопасность.

## Конфиденциальность

Приложение не запрашивает GPS, контакты или микрофон. Токен API хранится на вашем сервере в переменной окружения. В запросе статуса клиент получает все 27 статусов, выбранная область не передаётся отдельно. Сервер и сайт карты всё равно видят обычные сетевые сведения, например IP. Безопасность и дальнейшее хранение журналов своего хостинга контролируете вы. Не присылайте пароли Apple ID и API-токен в чат или в Telegram-архив.

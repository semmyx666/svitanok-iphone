# Изменения 0.2

- Добавлен GitHub Actions workflow: стандартный бесплатный macOS runner для публичного репозитория, backend-тесты, тесты упаковки, Swift Simulator tests, ARM64 device build и unsigned IPA artifact. Запуск вручную; подпись и Apple-пароли в CI не используются.
- Добавлены команды получения результата с Windows и Fedora, инструкция локальной бесплатной подписи на Windows через Sideloadly, объяснение 7-дневного срока и Wi-Fi после USB-сопряжения.
- Добавлена честная граница Fedora-only: сборка доступна через браузер/gh, нативный Linux sideload не подтверждён; практический путь установки — ваша имеющаяся Windows.
- Добавлен бесплатный тестовый вариант сервера на своём ПК с Cloudflare Quick Tunnel вместо VPS/домена, скрытый ввод API-токена, binding 127.0.0.1, cleanup процесса.
- Упаковщик отказывается паковать исходники вместо ARM64 device executable, simulator build, неправильный Info.plist, отсутствие AlarmKit description, некорректные права и symlink. Это не заменяет полную проверку настоящего бинарника Xcode.
- Доработана остановка звучащего AlarmKit-сигнала: используется stop, затем отменяются оставшиеся сигналы текущей группы.
- Обновлена версия сборки 0.2.0 и 2; правила основной сигнал/резерв/foreground не менялись.
- Повторены 84 Python-теста 20 раз, проведены actionlint и smoke-test Linux launcher с замоканным туннелем.

## Не выдаётся за исправленное

Ночной перенос в фоне/при заблокированном телефоне; гарантии исполнения сети; ежедневные повторения; точная карта дронов; проверенная совместимость Sideloadly/AltServer с вашим устройством; успешная macOS-сборка от вашего имени; работа звука на настоящем iPhone. Эти пункты не скрыты и не подменены журналами тестов сервера.

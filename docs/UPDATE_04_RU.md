# 0.4 — данные без собственного API-ключа и сервера

По умолчанию приложение напрямую запрашивает публичный API UA Siren:
https://siren.pp.ua/api/v3/alerts/{UID}
Документация и лимит (50 запросов/минуту/IP): https://github.com/PaulAnnekov/uasiren
Приложение выполняет примерно 4 запроса в минуту при открытом приложении.

## Что настроить
1. Отключить прежний будильник и резерв в старом приложении.
2. Установить новый IPA через iloader с тем же Apple Account.
3. Настройки → Источник → Без ключа · UA Siren (по умолчанию).
4. Выбрать район/громаду. Вінницький район UID36; Вінницька громада UID155.
5. Проверить связь при открытом приложении и включённом интернете.
Ключ, подписка и собственный HTTPS-сервер для этого режима не нужны.

## Достоверность и покрытие
- Используются 1589 UID, совпавших по идентификатору И названию между справочниками. Не каждый населённый пункт Украины.
- Родительские области/районы взяты из публичного дерева регионов, не угаданы по названиям.
- AIR на родительском районе/области учитывается для громады. Соседний район не подставляется.
- Пустой список регионов, неверный UID, отсутствующее activeAlerts, ошибка, старый HTTP Date → неизвестно, не отбой.
- HTTP Date проверяет свежесть ответа, НЕ доказывает своевременность данных первичного поставщика. У публичного посредника возможны задержки и отказы.
- Учитывается воздушная тревога AIR. Другие опасности не заменяют официальные оповещения.
- В случае недоступности источника обычный сигнал остаётся; если эксперимент уже перенёс его — остаётся резерв на предельное время.
- В приложении виден настоящий источник siren.pp.ua; его данные не выдаются за прямой alerts.in.ua API.
- Режим «Мой сервер · alerts.in.ua» сохранён для будущего собственного токена.

Перенос остаётся экспериментом только при открытом активном приложении; резерв обязателен.
Обычный системный AlarmKit-сигнал не требует интернета. Физическое ночное испытание ещё не выполнено.
Установка IPA не означает подтверждение поведения динамика и блокировки на реальном устройстве.

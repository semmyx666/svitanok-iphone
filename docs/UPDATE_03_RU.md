# Обновление 0.3 — промежуточная версия, не готовый ночной перенос

## Что изменено
- Большие часы — кнопка, открывающая отдельный экран с колёсиком времени и календарём.
- Поиск среди 1622 UID источника: районы, громады, области; это НЕ каждый населённый пункт Украины.
- Вінницький район UID 36, Гайсинський район UID 37, Вінницька громада UID 155 — раздельно.
- Новый маршрут сервера /v2/status?uid=36 на основе полного v2 IoT feed alerts.in.ua.
- Нет подстановки статуса области вместо выбранного района: старый сервер/неверный UID/пустая позиция/ошибка → неизвестно.
- Старые планы и настройки декодируются без потери системных идентификаторов.
- Понятные предупреждения на главном экране и в настройках.
- XCTest политики и миграции + настоящие XCUITest на iPhone Simulator со снимками экрана.

## Что НЕ изменилось
- Системный будильник по времени использует AlarmKit. Подтверждение на реальном устройстве необходимо.
- Автоматическое ожидание отбоя с закрытым экраном НЕ реализовано. Фоновый опрос не гарантируется iOS.
- Данные тревог не подключены: нужен собственный токен источника и обновлённый HTTPS-прокси.
- Перенос только при активном открытом приложении, включённом эксперименте и свежих данных.
- Проверка около 15 секунд; после обнаружения отбоя после выбранного времени ставится сигнал через 5 секунд.
- Резерв в предельное время может прозвучать при продолжающейся тревоге.
- Это не средство оповещения гражданской защиты, не доказательство безопасности и не готовое решение «не проспать школу».

## Почему не добавлен просто push
Приложения оповещения получают обычные удалённые уведомления от серверов APNs. Для надёжного условного будильника требуется не только доставка уведомления, но и изменение системного расписания; Apple прямо не гарантирует доставку фоновых уведомлений.
https://developer.apple.com/documentation/usernotifications/pushing-background-updates-to-your-app
https://developer.apple.com/documentation/AlarmKit
Не используем скрытое постоянное аудио, VoIP или геолокацию как обход фоновых ограничений.

## Установка обновления
1. Не удалять старое приложение до проверки плана. В старом приложении отключить текущий будильник и резерв.
2. Скачать новый IPA на Fedora, открыть iloader, выбрать тот же Apple Account и iPhone, Import IPA.
3. По возможности сохранить bundle ID ua.semmyx.svitanok; iloader может изменить его при подписи.
4. Открыть приложение. В настройках выбрать нужный район/громаду.
5. Для районов обновить сервер: server/app.py, server/locations.json, server/Dockerfile. Новый IPA не обновляет сервер автоматически.
6. Проверить обычный сигнал «через 2 минуты» с заблокированным экраном. Оставить резерв в системных «Часах».
7. Для фонового ожидания отбоя этот IPA НЕ подходит. Не считать симулятор доказательством ночного поведения на устройстве.
